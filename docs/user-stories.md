## 유저스토리 작성 규칙

각 유저스토리는 다음 형식을 따릅니다:

```
**As a** [역할]
**I want to** [원하는 기능]
**So that** [목적/가치]

**수용 기준 (Acceptance Criteria)**:
- [ ] 기준 1
- [ ] 기준 2
- [ ] 기준 3
```

우선순위: **P0** (필수), **P1** (중요), **P2** (선택)

## 1. 시스템 운영자 유저스토리

### US-001: 파일 업로드
**As a** 시스템 운영자  
**I want to** 시험지 파일(PDF, 이미지, HWP)을 업로드할 수 있어야 한다  
**So that** 문항 추출 작업을 시작할 수 있다

**우선순위**: P0

**수용 기준**:
- [x] 단일 파일 또는 다중 파일 업로드 가능
- [x] 파일 형식 검증 (PDF, PNG, JPG) *(HWP는 로드맵)*
- [x] 파일 크기 제한 검증 (PDF/이미지 50MB) *(HWP 20MB는 로드맵)*
- [ ] 업로드 진행률 표시
- [x] 업로드 완료 후 소스 문서 메타데이터 입력 폼 표시

## 6. 코드 기준 진행 현황 (2026-01-29 업데이트)

이 섹션은 **요구사항/PRD가 아니라, 현재 레포의 실제 코드 기준**으로 “어디까지 구현되어 있는지”를 요약합니다.

### 6.1 범례(상태 정의)
- **완료**: 화면/엔드포인트가 존재하고, 실제 데이터 연동까지 포함해 동작
- **부분(목업/스캐폴딩)**: 화면(UI 목업) 또는 API 스캐폴딩은 있으나, 핵심 기능(연동/비동기 처리/검색 필터 등)이 미완
- **미착수**: 관련 코드가 없거나, 문서/모델만 있고 기능 플로우가 없음

### 6.2 프론트엔드(Next.js) 현황
- **구현 완료된 화면**:
  - 공통: `/`, `/login`, `/forgot-password`, `/reset-password`, `/settings`
  - 운영자: `/operator`, `/operator/upload`, `/operator/ingestions`, `/operator/review`, `/operator/problems`
  - 교사: `/teacher`, `/teacher/search`, `/teacher/problems/[id]`, `/teacher/exams`, `/teacher/exams/new`, `/teacher/exams/preview`
  - 학생: `/student`, `/student/exams`, `/student/exams/[id]/result`
- **주요 구현 사항**:
  - 로그인/권한 기반 라우팅, 토큰 저장/갱신, API 호출/에러 처리 완료
  - 파일 업로드 실제 동작(파일 선택/전송), 검색/페이지네이션 실제 동작, 시험지 생성/다운로드 실제 동작 완료
  - 프로필 관리, 비밀번호 변경, 비밀번호 재설정 기능 완료

### 6.3 백엔드(Django/DRF) 현황
- **인증(JWT)**:
  - `POST /api/v1/auth/register/` (조직 + admin 유저 생성) ✅
  - `POST /api/v1/auth/token/`, `POST /api/v1/auth/token/refresh/` ✅
  - `GET /api/v1/auth/me/`, `PATCH /api/v1/auth/me/` ✅
  - `POST /api/v1/auth/password/change/` ✅
  - `POST /api/v1/auth/forgot-password/`, `POST /api/v1/auth/reset-password/` ✅
- **리소스 CRUD**:
  - `subjects`, `chapters`, `tags` ✅
  - `source-documents` (파일 업로드 + 확장자/용량 검증 + `IngestionJob` 자동 생성) ✅
  - `ingestion-jobs` (ReadOnly, 재시도 기능 포함) ✅
  - `problems` (검색 필터/정렬, 복구 기능 포함) ✅
  - `review-tasks` (승인/반려, 통계 API 포함) ✅
  - `exam-papers` (추천, 미리보기, PDF 생성/다운로드, 문항 추가/제거 포함) ✅
  - `classes` (반/학생군 관리) ✅
  - `exam-attempts` (시험지 풀이, 제출, 결과 조회, 오답 노트 포함) ✅
- **주요 구현 사항**:
  - 마이그레이션 파일 생성 완료 (`0001_initial.py`, `0002_passwordresettoken.py`, `0003_student_models.py`)
  - 검색 필터/정렬 로직 구현 완료
  - PDF 생성/다운로드 API 구현 완료
  - 검수 워크플로우(승인/반려/이력 기록) 구현 완료
  - 시험지 문항 관리(add_item/remove_item) 구현 완료
  - 학생 시험지 풀이/제출/결과 조회 기능 구현 완료
