## 유저스토리 작성 규칙

각 유저스토리는 다음 형식을 따릅니다:

```
**As a** [역할]
**I want to** [원하는 기능]
**So that** [목적/가치]

**수용 기준 (Acceptance Criteria)**:
- [ ] 기준 1
- [ ] 기준 2
- [ ] 기준 3
```

우선순위: **P0** (필수), **P1** (중요), **P2** (선택)

## 1. 시스템 운영자 유저스토리

### US-001: 파일 업로드
**As a** 시스템 운영자  
**I want to** 시험지 파일(PDF, 이미지, HWP)을 업로드할 수 있어야 한다  
**So that** 문항 추출 작업을 시작할 수 있다

**우선순위**: P0

**수용 기준**:
- [ ] 단일 파일 또는 다중 파일 업로드 가능
- [ ] 파일 형식 검증 (PDF, PNG, JPG) *(HWP는 로드맵)*
- [ ] 파일 크기 제한 검증 (PDF/이미지 50MB) *(HWP 20MB는 로드맵)*
- [ ] 업로드 진행률 표시
- [ ] 업로드 완료 후 소스 문서 메타데이터 입력 폼 표시

---

### US-002: 소스 문서 메타데이터 입력
**As a** 시스템 운영자  
**I want to** 업로드한 소스 문서의 메타데이터를 입력할 수 있어야 한다  
**So that** 출처 및 저작권 정보를 추적할 수 있다

**우선순위**: P0

**수용 기준**:
- [ ] 제목 입력 필드
- [ ] 출처 입력 필드 (저작권자, 출판사, 출제기관)
- [ ] 출제시기 입력 필드 (연도, 월, 회차)
- [ ] 라이선스 정보 입력 필드
- [ ] 메타데이터 저장 후 문항 추출 작업 시작

### US-025: 프로필 관리
**As a** 사용자  
**I want to** 내 프로필 정보를 확인하고 수정할 수 있어야 한다  
**So that** 개인 정보를 관리할 수 있다

**우선순위**: P1

**수용 기준**:
- [ ] 프로필 정보 표시 (이름, 이메일, 역할, 조직)
- [ ] 프로필 정보 수정 기능
- [ ] 비밀번호 변경 기능
- [ ] 프로필 이미지 업로드 (선택적)

## 5. 우선순위 요약

### P0 (필수 - MVP)
- US-001 ~ US-005: 운영자 기본 기능
- US-008 ~ US-014: 교사 기본 기능
- US-023: 로그인

### P1 (중요)
- US-006, US-007: 운영자 고급 기능
- US-015: 교사 템플릿 관리
- US-024, US-025: 공통 기능

### P2 (선택 - 로드맵)
- US-016: 교사 반/학생군 설정
- US-017 ~ US-020: 학생 시험지 풀이/제출/결과
- US-021, US-022: 학생 고급 기능
