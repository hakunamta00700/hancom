# 제품 요구사항 문서 (PRD)
## 학원용 문제 제출기 + AI 학습 도우미 시스템

**버전**: 1.0  
**작성일**: 2026-01-27  
**관련 문서**: [requirements.md](requirements.md), [user-stories.md](user-stories.md), [architecture.md](architecture.md)

---

## 1. 제품 개요

### 1.1 목표
시험지(문서/이미지)에서 문항을 자동 추출하여 DB화하고, 과목/단원/유형/난이도/출제시기 등으로 검색·필터링하여 새로운 시험지를 조립할 수 있는 시스템을 구축합니다. 최종적으로는 학원에서 사용할 수 있는 문제 제출기와 학생 개인이 사용 가능한 AI 학습 도우미로 발전시킵니다.

### 1.2 핵심 가치 제안
- **효율적인 문제 관리**: 시험지 문서를 업로드하면 자동으로 문항을 추출하고 분류하여 DB에 저장
- **스마트한 시험지 제작**: 조건 기반 검색으로 원하는 문항을 빠르게 찾아 시험지 조립
- **체계적인 학습 지원**: (로드맵) 학생의 약점 단원 분석 및 맞춤형 문제 추천

### 1.3 타겟 사용자
1. **시스템 운영자**: 콘텐츠 확보 및 입력, 검수, DB 관리 담당
2. **선생님**: 학원에서 시험지 제작 및 배포, 학생 관리
3. **학생**: 시험지 풀이 및 학습 (MVP에서는 최소 기능)

## 2. 제품 범위

### 2.1 MVP (1차 릴리즈)

#### 2.1.1 콘텐츠 수집 및 관리
- 시험지/문서 업로드 (PDF, 이미지) *(HWP 업로드는 로드맵/옵션)*
- 자동 문항 추출 (페이지/문항 단위 분할)
- OCR 기반 텍스트 추출 (가능한 경우)
- LLM 기반 자동 태깅 (과목, 단원, 유형, 난이도 추정)
- 문항 메타데이터 검수 워크플로우 (운영자)
- 저작권/출처 정보 관리

#### 2.1.2 문항 검색 및 필터링
- 다중 조건 검색 (과목, 단원, 유형, 난이도, 출제시기, 키워드)
- 검색 결과 미리보기
- 문항 상세 정보 확인

#### 2.1.3 시험지 제작
- 조건 기반 문항 선택
- 중복 방지 (같은 문항이 여러 번 포함되지 않도록)
- 난이도 밸런싱 (선택적)
- 시험지 미리보기
- 시험지 내보내기 (PDF 우선, HWP는 로드맵/옵션)

#### 2.1.4 권한 및 보안
- 역할 기반 접근 제어 (RBAC)
- 조직(학원) 단위 데이터 격리
- 감사 로그 (누가, 언제, 무엇을 했는지 기록)
- 저작권 정보 필수 입력

### 2.2 로드맵 (2차 이후)

#### 2.2.1 고급 분석 기능
- 선수 단원/개념 그래프 기반 분석 (문항이 요구하는 단원 자동 분석)
- 문항 간 유사도 분석

#### 2.2.2 AI 기반 문제 생성
- 유사 문항 생성 (생성 근거/출처/유사도 표시)
- 생성 문항 검수 워크플로우 (검수 없이는 배포 불가)

#### 2.2.3 학생 AI 학습 도우미
- 오답 노트 자동 생성
- 약점 단원 추천
- 맞춤형 퀴즈 생성
- 학습 진도 추적
- *(로드맵)* 온라인 시험지 풀이/제출/채점(학생 포털)

## 3. 페르소나 및 사용자 워크플로우

### 3.1 시스템 운영자 (콘텐츠 관리자)

**목표**: 고품질의 문항 DB를 구축하고 유지보수

**워크플로우**:
1. 콘텐츠 소스 확보 (자체 제작, 제휴, 공개 문항)
2. 시험지/문서 업로드
3. 자동 추출/OCR/LLM 태깅 실행
4. 검수 작업 (원문 이미지, 추출된 텍스트, 자동 태깅 결과 검토)
5. 메타데이터 수정/보완 (과목, 단원, 유형, 난이도, 출제시기 등)
6. 저작권/출처 정보 입력
7. 승인/반려 결정
8. 승인된 문항 DB 배포 (교사/학생 노출)

**주요 기능**:
- 대량 업로드 및 배치 처리
- 검수 대시보드 (대기 중인 문항 목록)
- 버전 관리 (문항 수정 이력)
- 삭제/비공개 정책 관리

### 3.2 선생님 (학원 출제 담당자)

**목표**: 수업에 맞는 시험지를 빠르게 제작

**워크플로우**:
1. 반/학생군 설정 (선택적)
2. 시험지 조건 설정 (과목, 단원, 유형, 난이도, 문제 수)
3. 추천 문항 후보 검토
4. 문항 선택/제외
5. 시험지 미리보기 및 난이도 분포 확인
6. 시험지 생성 및 배포 (PDF 다운로드 또는 학생에게 직접 배포)
7. (로드맵) 학생 풀이 결과 확인

**주요 기능**:
- 고급 검색 및 필터링
- 시험지 빌더 (드래그 앤 드롭 또는 체크박스 선택)
- 난이도 분포 차트
- 시험지 템플릿 관리

### 3.3 학생 (개인 학습자)

**목표**: *(로드맵)* 온라인 시험지 풀이/오답 분석/개인 맞춤 학습

**로드맵 워크플로우**:
1. 오답 노트 자동 생성
2. 약점 단원 확인
3. 유사 문항 추천 및 연습
4. 맞춤형 퀴즈 생성
5. 시험지 풀이/제출/채점(정답지 기반)

## 4. 핵심 기능 상세

### 4.1 문항 추출 파이프라인

**입력**: PDF, 이미지 파일, HWP 파일

**처리 단계**:
1. 문서 → 이미지 변환 (PDF는 PyMuPDF, HWP는 Windows 전용 서비스)
2. 레이아웃 분석 (헤더/푸터/단 분할) - OpenCV 기반
3. 문항 번호 감지 (OCR - EasyOCR)
4. 문항 영역 크롭 및 이미지 저장
5. 텍스트 추출 (OCR)
6. LLM 기반 자동 태깅 (과목, 단원, 유형, 난이도 추정)

**출력**:
- 문항 이미지 (크롭된 PNG)
- 추출된 텍스트 (JSON)
- 자동 태깅 결과 (메타데이터)

**참고**: 현재 구현된 `extract_problems.py`는 PDF → 이미지 → OCR로 문항 번호 감지 → 크롭 저장까지 수행합니다.

### 4.2 검수 워크플로우

**검수 대기 상태**: 자동 추출/태깅 완료 후, 운영자 검수 대기

**검수 화면 구성**:
- 원문 이미지 (전체 페이지)
- 크롭된 문항 이미지
- 추출된 텍스트 (수정 가능)
- 자동 태깅 결과 (수정 가능)
- 메타데이터 입력 폼 (과목, 단원, 유형, 난이도, 출제시기, 저작권 정보)

**검수 액션**:
- 승인: DB에 공개
- 반려: 수정 요청 또는 삭제
- 수정: 메타데이터 수정 후 재제출

### 4.3 문항 검색

**검색 조건**:
- 과목 (국어, 수학, 영어, 과학 등)
- 단원 (과목별 단원 트리)
- 유형 (객관식, 서술형, 지문형 등)
- 난이도 (1~5 또는 Easy/Medium/Hard)
- 출제시기 (연도, 월, 회차)
- 키워드 (텍스트 검색)

**검색 결과**:
- 문항 목록 (이미지 썸네일, 제목/지문 일부, 태그)
- 정렬 옵션 (최신순, 난이도순, 출제시기순)
- 페이지네이션

### 4.4 시험지 조립

**조건 설정**:
- 과목, 단원, 유형, 난이도 범위
- 총 문제 수
- 난이도 분포 (예: 쉬움 30%, 보통 50%, 어려움 20%)

**문항 선택**:
- 자동 추천 (조건에 맞는 문항 자동 선택)
- 수동 선택 (검색 결과에서 직접 선택)
- 중복 방지 (이미 선택된 문항은 제외)

**시험지 미리보기**:
- 문항 목록
- 난이도 분포 차트
- 총 문제 수, 예상 소요 시간

**내보내기**:
- PDF 생성 (우선)
- *(로드맵/옵션)* HWP 생성 (Windows 전용 서비스)

**참고**: 현재 구현된 `main.py`, `main2.py`, `main3.py`는 HWP 자동화 실험 코드입니다.

## 5. 비기능 요구사항

### 5.1 성능
- 문항 추출 작업(크롭+OCR): 페이지당 평균 10초 이내 *(입력 품질/서버 스펙에 따라 변동)*
- 자동 태깅(LLM): 비동기 처리, 배치/재시도 포함 **평균 1~5분 이내** 목표(대량 처리 시 큐 대기 포함)
- 검색 응답 시간: 1초 이내 (일반적인 쿼리)
- 시험지 생성: 5초 이내 (PDF)

### 5.2 정확도 목표
- 문항 추출 성공률: 95% 이상 (정상적인 레이아웃의 시험지)
- OCR 정확도: 90% 이상 (명확한 스캔 이미지)
- 자동 태깅 정합률: 70% 이상 (검수 후 수정 필요)

### 5.3 확장성
- 동시 사용자: 100명 이상 지원
- 문항 DB: 10만 개 이상 저장 가능
- 파일 저장: S3 호환 스토리지 사용

### 5.4 보안 및 규정 준수
- 역할 기반 접근 제어 (RBAC)
- 조직(학원) 단위 데이터 격리
- 감사 로그 (모든 중요 작업 기록)
- 저작권 정보 필수 입력 (출처, 라이선스, 사용 범위)
- 개인정보 최소 수집 원칙

### 5.5 데이터 보존 및 삭제
- 문항 데이터: 삭제 요청 시 즉시 삭제 (GDPR 준수)
- 감사 로그: 1년 보관
- 생성 문항: 검수 없이는 배포 불가 (안전장치)

## 6. 성공 지표 (KPI)

### 6.1 사용성 지표
- 문항 추출 성공률: 95% 이상
- 검수 완료 시간: 평균 5분/문항 이내
- 시험지 제작 시간: 평균 10분 이내 (조건 설정 → PDF 다운로드)

### 6.2 품질 지표
- 자동 태깅 정합률: 70% 이상 (검수 후 수정 비율)
- 사용자 만족도: NPS 50 이상

### 6.3 비즈니스 지표
- 등록된 문항 수: MVP 출시 후 3개월 내 1만 개 이상
- 활성 사용자 수: 월간 활성 사용자 100명 이상
- 시험지 생성 수: 월간 500개 이상

## 7. 리스크 및 대응 방안

### 7.1 기술적 리스크

**리스크**: OCR 정확도가 낮은 경우
- **대응**: 다중 OCR 엔진 지원, 수동 검수 워크플로우 강화

**리스크**: LLM 태깅 오류
- **대응**: 검수 필수, 프롬프트 버전 관리, 모델 A/B 테스트

**리스크**: HWP 파일 처리 (Windows 전용)
- **대응**: HWP는 옵션 기능으로 분리, Windows 전용 마이크로서비스로 분리

### 7.2 법적/규제 리스크

**리스크**: 저작권 위반
- **대응**: 출처 정보 필수 입력, 사용 범위 명시, 정기적인 저작권 검토

**리스크**: 개인정보 보호
- **대응**: 최소 수집 원칙, 데이터 암호화, 접근 제어

### 7.3 운영 리스크

**리스크**: 대량 업로드 시 시스템 부하
- **대응**: 비동기 작업 큐 (Celery/RQ), 배치 처리 최적화

**리스크**: 데이터 손실
- **대응**: 정기적인 백업, 스토리지 복제

## 9. 용어집

- **문항 (Problem)**: 시험지의 개별 문제
- **지문 (Passage)**: 문항의 본문 또는 읽기 자료
- **선택지 (Choice)**: 객관식 문항의 보기
- **단원 (Chapter)**: 과목 내 세부 학습 단위
- **시험지 (ExamPaper)**: 여러 문항을 모아 만든 시험 문서
- **소스 문서 (SourceDocument)**: 원본 시험지 파일 (PDF, 이미지, HWP)
- **검수 (Review)**: 자동 추출/태깅 결과를 사람이 검토하고 수정하는 과정
- **태깅 (Tagging)**: 문항에 메타데이터(과목, 단원, 유형 등)를 부여하는 과정
