## 1. 정보 아키텍처 (IA)

### 1.1 전체 구조

```
학원용 문제 제출기 시스템
├── 공통
│   ├── 로그인/로그아웃
│   ├── 프로필 관리
│   └── 알림
├── 운영자 콘솔
│   ├── 대시보드
│   ├── 파일 업로드
│   ├── 추출 작업 관리
│   ├── 검수 작업
│   └── 문항 관리
├── 교사 콘솔
│   ├── 대시보드
│   ├── 문항 검색
│   ├── 시험지 제작
│   ├── 시험지 관리
│   └── (로드맵) 학생 관리
└── 학생 화면
    ├── 시험지 목록
    ├── 문제 풀이
    └── 결과 확인
```

### 1.2 네비게이션 구조

**운영자**:
- 상단 네비게이션: 로고 | 대시보드 | 업로드 | 검수 | 문항 관리 | 설정
- 사이드바: 조직 관리 | 사용자 관리 | 감사 로그

**교사**:
- 상단 네비게이션: 로고 | 대시보드 | 문항 검색 | 시험지 제작 | 시험지 목록 | 설정
- 사이드바: (로드맵) 반 관리 | 학생 관리

**학생**:
- 상단 네비게이션: 로고 | 시험지 목록 | (로드맵) 오답 노트 | (로드맵) 학습 현황
- 사이드바: 없음 (간단한 구조)

```
┌─────────────────────────────────────┐
│         [로고] 학원 문제 제출기        │
│                                     │
│  ┌───────────────────────────────┐ │
│  │ 이메일                          │ │
│  │ [___________________________] │ │
│  └───────────────────────────────┘ │
│                                     │
│  ┌───────────────────────────────┐ │
│  │ 비밀번호                        │ │
│  │ [___________________________] │ │
│  └───────────────────────────────┘ │
│                                     │
│  [ ] 자동 로그인                     │
```

## 6. 반응형 디자인

### 6.1 데스크톱 (≥1024px)
- 사이드바 네비게이션
- 2-3열 그리드 레이아웃
- 상세 정보 표시

### 6.2 태블릿 (768px - 1023px)
- 접을 수 있는 사이드바
- 2열 그리드 레이아웃
- 터치 친화적 버튼

### 6.3 모바일 (<768px)
- 햄버거 메뉴
- 1열 레이아웃
- 스와이프 제스처 지원

- **키보드 네비게이션**: 모든 기능을 키보드로 접근 가능

- **색상 대비**: WCAG 2.1 Level AA 준수
- **폰트 크기**: 최소 14px, 확대 가능
