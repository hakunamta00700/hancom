# Project Brief

## 프로젝트 개요
- **프로젝트명**: hancom
- **목표**: 시험지(PDF/이미지)에서 문항을 자동 추출해 DB화하고, 검색/필터링을 통해 시험지를 조립할 수 있는 시스템(MVP).

## 현재 구현(레포 기준)
- **백엔드**: Django(DRF) 기반 API/모델 스캐폴딩 (`backend/`)
- **프론트엔드**: Next.js(App Router) (`frontend/`)
- **로컬 인프라**: PostgreSQL, Redis를 Docker Compose로 구동

## 범위
- MVP 범위는 `docs/prd.md`, `docs/requirements.md`를 따른다.
